# Xinxin Frontend

私人 Agent 平台前端和手机客户端，独立仓库。

目前为本地调研基线，尚未生成 UI 或安装应用依赖。主人确认布局和功能评分后开始设计与实现。

远程仓库：<https://github.com/qing1989620/xinxin-frontend>

## 已确定的产品方向

- Agent 对话有一级直达入口。
- 响应式界面，暖白底、深灰文字、单一强调色、清晰网格和留白。
- 提供任务状态、文件和产物等有用交互。
- 可向手机安装形态演进，首版目标系统等待确认。
- 后端执行、数据库和密钥不进入此仓库。

拟选 Vite + React + TypeScript；如果保留公开内容站并要求服务端渲染，再比较仅承担前端职责的 Next.js。此项尚未形成最终技术决策。

审查流程：[audit-plan.md](docs/audit-plan.md)。
