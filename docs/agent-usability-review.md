## 发现与处理

| 旅程 | 实施与证据 |
| --- | --- |
| 对话只有终端，难以理解进度 | 主时间线展示模型公开文字和平台真实阶段；终端默认折叠。长命令等待按目的、已用时间和实际输出解释；用稳定命令标识替换等待状态，终态不再显示运行中。合成进度浏览器截图 readable-progress.png。 |
| 预算耗尽无法直接续任务 | “继续原任务”直接调用新续接接口，明确沿用当前可见授权/目标，使用新一轮预算；重复点击忙态禁用，网络不确定保留请求标识。浏览器直接续接同一对话成功；后端真实模型验收另记录。 |
| 批量清理 | 最近/归档可选最多100段，筛选全选，显示名称和汇总；确认勾选前禁用永久删除。浏览器验证两段预览并取消，没有用UI删除真实内容。原子删除和共享引用由后端专门回归。 |
| 记忆无法勾选 | 只读下先明示勾选会切为工作区；真正勾选后更新可见权限，取消/切回只读撤销授权，执行中固定。合成浏览器勾选后反复打开仍选中；未写入真实主人记忆。 |
| 图片静默灰块 | 去除 AbortSignal.any/timeout 静态方法依赖，手动链接取消与超时，覆盖响应体读取；这是旧WebView兼容性修复，未声称已在主人设备复现其具体版本。鉴权缩略预览减小传输量，旧后端404回原接口；失败明确说明和重试，卸载后的迟到响应不写状态，释放Blob URL。卡片内不嵌套重试按钮。 |
| Agent入口跳新对话 | 按后端和主人持久保存最后选择的对话标识；Android Preferences与网页存储不含正文或密钥。“新建”显式独立；不存在链接清理后回新对话。提交响应迟到不强行导航，返回前台重开观察流，不重新提交任务。 |
| 手机输入区过高 | 默认一行，根据真实排版增高，最多四行，之后内部滚动；清空或删减后缩回。去除旧容器重复内边距，宽度变化重新测量。 |

## 实际覆盖

- 34项 Vitest 通过，TypeScript及生产构建通过。含续接请求/幂等、旧服务提示、公开进度、记忆交互、缺少AbortSignal静态方法、响应体读取期间中止/超时、预览兼容、原生持久选择恢复与后端/主人隔离。
- 本地真实浏览器 + 隔离数据库 + 模拟模型：同会话直接续接、批量预览/取消、记忆勾选、合成简历图片成功/故意缺失后重试。图片请求走真实本地鉴权与解码接口；无主人证书或私人截图。
- 浏览器运行中离开Agent，再返回同一会话；18秒延迟模型任务期间刷新页面，之后同一对话显示完成结果。没有重复提交。模型为合成延迟夹具，不能当真实SSH证明。
- 390×844 同源iframe手机视口（桌面浏览器内，非实体Android）：一、二、四、六行和中文自动折行，超过四行滚动、删减后缩回。截图 composer-mobile-*.png；四行与六行高度相同。
